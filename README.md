# Combina Casa

Site brasileiro de compatibilidade para casa inteligente. A primeira versão foi
desenhada para ser pequena, verificável e fácil de operar.

## Para quem não programa

Abra o arquivo [SETUP.md](SETUP.md). Ele explica os poucos passos manuais e o
significado de cada botão.

## Comandos de desenvolvimento

```bash
pnpm install
pnpm dev
pnpm check
pnpm build
```

O build sempre executa a validação do conteúdo antes de gerar o site.
